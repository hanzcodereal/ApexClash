# Apex Clash

Game fighting 2D **Mecha vs Demi-Human** untuk Android (offline, single player).

- Versi: **1.0.0**
- Bahasa pemrograman: **Kotlin** (pembungkus WebView) + game web HTML/JS di `app/src/main/assets/www`
- Package: `id.hanzdev.apexclash`

## Build APK Release (GitHub Actions, manual)

1. Upload seluruh isi project ini ke repository GitHub (isi folder langsung di root repo).
2. Buka tab **Actions** -> pilih **Build APK Release** -> **Run workflow**.
3. Setelah selesai, unduh APK dari bagian **Artifacts** (`ApexClash-1.0.0-release`).

APK ditandatangani dengan keystore di `keystore/apexclash-release.jks`, jadi langsung bisa diinstal.

## Kontrol

Layar sentuh: D-pad kiri + tombol serang/skill kanan. Tombol Back = Esc (jeda / kembali), tekan 2x cepat untuk keluar.
